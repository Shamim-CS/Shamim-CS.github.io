# Md Shamimul Islam: Personal Academic Website

Source for https://shamim-cs.github.io

A static site (plain HTML and CSS, no build step) served by GitHub Pages.

- `index.html`: bio, research interests, education, publications, projects, experience, awards, talks and service
- `publications.html`: full publication list, manuscripts under review and datasets
- `style.css`: styles, including dark mode
- `site.js`: dark mode switch and the animated MA-IDS illustration in the header
- `documents/CV_Md_Shamimul_Islam.pdf`: CV
- `img/`: profile photo and favicon
- `img/research/`: architecture figures from the papers, shown in Selected work and on the publications page
